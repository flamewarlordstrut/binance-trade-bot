# Binance Trade Bot — Independent Windows Distribution

An independent fork of [ccxt/binance-trade-bot](https://github.com/ccxt/binance-trade-bot), an automated cryptocurrency trading bot written in Python.

**[Download for Windows x64](https://github.com/YOUR_GITHUB_USERNAME/binance-trade-bot-windows/releases/latest/download/binance-trade-bot-windows-x64.exe)** · **[Release notes and files](https://github.com/YOUR_GITHUB_USERNAME/binance-trade-bot-windows/releases/latest)**

Windows executables are distributed through **GitHub Releases**. Download the `.exe` from the release's **Assets** section. The **Code → Download ZIP** option contains source code.

| File | Purpose |

Keep the executable's filename consistent across versions so the download link continues to work.

## Before running

1. Download the executable and any accompanying files from the same release.
2. Put them in a dedicated folder you can write to. Create `data`, `logs`, and `config` subfolders if the executable does not create them.
3. Copy `user.cfg.example` to `user.cfg` and fill in your own credentials and configuration. The supplied example uses `testnet=true`.
4. Review `supported_coin_list` and select your starting coin. An empty `current_coin` can cause the upstream bot to choose and buy a coin.
5. Follow any additional instructions in that release. For a console build that uses the upstream working-directory layout, open PowerShell in this folder and run:

```powershell
.\binance-trade-bot-windows-x64.exe
```

The example configuration does not start a funded trading session by itself. Do not publish your API credentials or upload your personal `user.cfg`.

## What the project does

The upstream bot monitors relative prices of configured cryptocurrencies and can trade between them through a bridge currency. Strategies, configuration, backtesting, and Docker instructions are documented in the [upstream README](README.upstream.md).

Trading can lose money. No returns are promised. A Windows release is packaging of this project, not evidence that a strategy is profitable or that exchange integrations are currently compatible.

## Source and release status

This repository contains the upstream Python implementation and additional distribution documentation. A compiled Windows executable is **not** included in the source archive. Release binaries are provided separately by this fork's maintainer and should be built from the published source for the corresponding tag.

Upstream dependency versions are preserved in `requirements.txt`. Windows packaging, dependency installation, and live exchange connectivity have not been validated as part of this source preparation. See [PUBLISH_RU.md](PUBLISH_RU.md) for the maintainer's publishing instructions.
